# Le fil de l'eau

Le **fil de l'eau** rassemble tous les messages émis par votre habitat : une porte qui s'ouvre,
une température qui dépasse un seuil, un équipement en panne.

Accès : menu **Fil de l'eau**.

---

## Les types de message

Chaque message a un type, qui indique son importance. C'est ce qui détermine sa couleur et
l'urgence de votre réaction.

| Type | Ce que cela signifie | Votre réaction |
|---|---|---|
| **État** | Information de fonctionnement normal | Aucune |
| **Veille** | Une surveillance vient de s'activer | Aucune |
| **Alerte** | Une situation demande votre attention | Vérifier |
| **Alarme** | Un événement anormal est en cours | Intervenir |
| **Dérangement** | Un équipement fonctionne mal sans être arrêté | Planifier une intervention |
| **Défaut** | Un équipement est en panne | Intervenir |
| **Danger** | Situation présentant un risque | Intervenir immédiatement |

!!! tip "Ne vous fiez pas qu'à la couleur"
    Le texte du message est rédigé par votre technicien pour être compréhensible.
    Il contient souvent la valeur en cause : « Température ballon trop haute (72) ».

---

## Acquitter un message

Acquitter, c'est dire au système : **« j'ai vu »**.

Cliquez sur le bouton d'acquittement du message.

Ce qui change :

- le message cesse de clignoter dans le fil de l'eau ;
- le visuel correspondant sur le [synoptique](synoptiques.md) cesse de clignoter ;
- les autres utilisateurs voient que quelqu'un a pris connaissance de l'événement.

!!! warning "Acquitter ne répare rien"
    Acquitter un défaut ne fait pas disparaître le problème. L'équipement reste en panne et le
    message reste visible, simplement plus discret.

    Si le défaut a réellement disparu, le message s'efface de lui-même.

!!! note "Un message acquitté peut revenir"
    Si la cause réapparaît après avoir disparu, un nouveau message est émis et se remet à
    clignoter. C'est normal : c'est un nouvel événement.

---

## Pourquoi un message réapparaît sans cesse

Un message qui revient toutes les quelques minutes signale généralement un équipement qui
oscille autour d'un seuil — il se déclenche, s'arrête, se redéclenche.

Ce n'est pas un problème d'affichage : c'est un symptôme réel.
Signalez-le au responsable de l'habitat, le réglage doit être revu.

---

## Recevoir les messages ailleurs

Les messages importants peuvent vous être envoyés par SMS, par messagerie instantanée ou
annoncés à voix haute sur des enceintes.

Pour cela, il faut que votre profil soit renseigné et que vous ayez demandé à être notifié.
Voir [Être notifié](notifications.md).

!!! note "Tous les messages ne sont pas notifiés"
    Seuls ceux que votre technicien a marqués comme tels déclenchent un envoi.
    C'est volontaire : être notifié de tout revient à n'être notifié de rien.

---

## Retrouver un ancien message

Le fil de l'eau ne montre que les messages **en cours** ou récents.
Pour chercher dans le passé, utilisez [l'historique](historique.md).
